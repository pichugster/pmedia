# pichugster · база — сайт на Astro

Это настоящий проект сайта (не конструктор). Быстрый, лёгкий, готов расти.
Ниже — всё простыми словами, без технического жаргона.

---

## Что уже готово

- **Главная** — та, что ты утвердил
- **Каталог стран** (`/strany`) — с рабочими фильтрами (Новичкам / AI / Монтаж / Блог / Низкие цены)
- **Гайды** (`/gaydy`) — список + страница статьи, один пример гайда уже внутри
- **Разделы** Заработок / Монтаж / Удалёнка / Материалы — пока заглушки «скоро», наполним по очереди

Дизайн, цвета и шрифты бренда лежат в одном файле: `src/styles/global.css`.

---

## Как опубликовать сайт (без терминала)

Самый простой путь для новичка — через GitHub + Cloudflare Pages. Терминал не нужен.

1. **Заведи аккаунт** на github.com и на cloudflare.com (бесплатно).
2. **Создай репозиторий** на GitHub и загрузи туда содержимое этой папки
   (кнопка “Add file” → “Upload files”, перетащи все файлы **кроме** папок
   `node_modules` и `dist`).
3. В Cloudflare открой **Workers & Pages → Create → Pages → подключи свой GitHub-репозиторий**.
4. В настройках сборки укажи:
   - Framework preset: **Astro**
   - Build command: `npm run build`
   - Output directory: `dist`
5. Нажми **Deploy**. Через пару минут сайт будет в сети по адресу вида `имя.pages.dev`.

> Vercel (vercel.com) работает так же — тоже подключает GitHub и сам всё собирает.

### Свой домен (не .ru)

Купи домен (например на Namecheap или Porkkun) — `.com` / `.co` / `.media`.
В Cloudflare Pages есть раздел **Custom domains** — добавляешь домен, следуешь подсказке. Готово.

## Как добавить новый гайд (сам, без кода)

1. Зайди в папку `src/content/guides/`.
2. Скопируй файл `s-chego-nachat.md` и переименуй (латиницей, например `higgsfield.md`).
3. Вверху файла заполни поля:
   ```
   ---
   title: "Название гайда"
   description: "Короткое описание"
   category: "Нейросети"
   date: 2026-06-15
   draft: false
   ---
   ```
4. Ниже пиши текст обычным языком. Заголовки — со `##`, списки — с `-`.
5. Сохрани. Если сайт на GitHub — он пересоберётся сам, и гайд появится.

Можно редактировать прямо на сайте GitHub в браузере — без установки чего-либо на компьютер.

## Что подключим дальше (модули)

- **Оплата и продукты** — пока заглушка. Платёжный сервис (на старте — выбранный тобой)
  подключается на странице продукта. Его можно сменить/добавить без переделки сайта.
- **Видеоуроки** — отдельный видеохостинг (Bunny Stream / Cloudflare Stream), вставляется
  на страницы уроков, когда дойдём до них.
- **Панель для контента (CMS)** — по желанию подключим визуальный редактор, чтобы добавлять
  гайды совсем как в конструкторе.

## Для разработчика (если захочешь запускать локально)

```bash
npm install      # один раз
npm run dev      # локальный просмотр на localhost:4321
npm run build    # собрать сайт в папку dist/
```

Нужен установленный Node.js (версия 18+).
